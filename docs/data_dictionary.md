# Data Dictionary

## policy_source.csv
Operational policy data including state, crop, plan, coverage level, status, and reported premium.

## acreage_source.csv
Field-level acreage and production-related attributes tied to policy, farm, tract, and field.

## warehouse_policy_fact.csv
Policy-level analytical warehouse fact used for downstream reporting.

## reference_crop_plan.csv
Reference data for valid crop and insurance-plan combinations.

## reporting_summary.csv
Aggregated state/crop reporting output used for reconciliation.
